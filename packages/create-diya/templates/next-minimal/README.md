# {{name}}

A Next.js app built with [DIYA](https://diya13.ai).

```sh
{{dev}}
```

Then open http://localhost:3000.

- `app/providers.tsx` holds the DIYA provider: your brand color, Light or Dark, and Next.js `Link`.
- `app/globals.css` names the CSS layer order and loads DIYA's styles. Your CSS wins.
- `app/page.tsx` is the page you see. `app/first-form.tsx` is the interactive part.
