# {{name}}

A Vite app built with [DIYA](https://diya13.ai).

```sh
{{dev}}
```

Then open http://localhost:5173.

- `src/providers.tsx` holds the DIYA provider: your brand color and Light or Dark.
- `src/index.css` names the CSS layer order and loads DIYA's styles. Your CSS wins.
- `src/App.tsx` is the page you see. `src/first-form.tsx` is the interactive part.
